# Nexirift Assistant

NEXA - (Nex)irift (A)ssistant, is Nexirift's solution to auto moderator.

This repository is under heavy maintenance as a lot of the code is poorly written.

## What is NEXA NOT?

NEXA is **not** a fully autonomous moderation system. Its primary purpose is to assist existing moderators by proactively flagging and removing problematic content. Currently, only virus detection is handled automatically; all other actions require moderator review and intervention.

## Features

- Spam detection
- NSFW detection
- Virus detection
- Phishing detection
- Notifications
  - Discord
  - Console
